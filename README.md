# HAY Engine

**Armenian-first AI infrastructure for language, voice and creator workflows.**

HAY Engine is being built with Armenian as the priority language and English/Russian as first-class secondary languages.

Initial product surface:

- Armenian text normalization and pronunciation layer
- Multilingual script generation contracts
- Armenian-first voice provider routing
- Caption/timestamp contracts
- Reel/storyboard generation pipeline
- Armenian / English / Russian UI
- Provider-agnostic API architecture for LLM, TTS, STT, image and video models

> Status: early MVP foundation.
