# HAY Studio Command V2

This visual/product pass keeps all existing MarketingOS business logic intact and layers a new command-center experience on top.

## Added
- Black / white / electric-green Studio visual system aligned with the public landing.
- Live `/api/health` readiness rail for AI, voice, video, database, social connectors and Armenian quality.
- Functional Cmd/Ctrl+K command palette with keyboard navigation.
- Safer rollback: original `marketing.css` remains untouched; `marketing-v2.css` is an override layer.

## Product principle
The Studio should answer four questions immediately:
1. What does HAY know about my business?
2. What is HAY doing now?
3. What needs my approval/setup?
4. What should be created or published next?
